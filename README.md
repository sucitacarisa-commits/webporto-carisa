# Portofolio Carisa Nur Sucita

## Menjalankan secara lokal
Buka `index.html` di browser. Tidak perlu framework, instalasi, atau proses build.

## Publikasi ke GitHub Pages
1. Buat repository GitHub baru.
2. Unggah `index.html`, `style.css`, `script.js`, dan folder `assets`.
3. Buka **Settings → Pages**.
4. Pada bagian Build and deployment, pilih **Deploy from a branch**.
5. Pilih branch `main` dan folder `/ (root)`, lalu simpan.

Gambar pada folder `assets` diambil dari screenshot desain yang diberikan. Silakan ganti dengan file gambar asli beresolusi lebih tinggi jika tersedia.
